# Funciones administrativas pendientes
Esta carpeta NO contiene un backend desplegado.
Inicializar con Firebase CLI cuando se elija el proyecto y la región.
Operaciones previstas: crear/dar de baja cuentas, consultar actividad, publicar y borrar música.
Validar identidad y custom claim admin en cada endpoint. Nunca aceptar un rol enviado por el cliente como autorización.
Para bajas definir política de eliminación de Auth, perfil, favoritos e historial. No almacenar contraseñas.
La extracción de audio requiere decidir conversión local Android o servicio de procesamiento; no basta con cambiar la extensión de MP4 a MP3.
